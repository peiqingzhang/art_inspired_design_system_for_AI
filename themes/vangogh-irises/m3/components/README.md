# Van Gogh — Irises (1889) (M3) Component Library

Strict Material Design 3 token set. Generated by the `tokens-to-components` skill from DTCG design tokens.

## Setup

1. Include `theme.css` in your app root:
   ```js
   import './components/theme.css';
   ```
2. Install peer dependencies: `react`, `react-dom``, `typescript`

## Usage

```tsx
import { Button, Card, Input, Chip } from './components';

<Button variant="filled" onClick={() => {}}>Save</Button>
<Card variant="elevated"><Card.Header title="Hello" /></Card>
```

## Token Requirements

This library requires the following CSS custom properties (from `theme.css`):
- `--color-*` — from `color.sys.light.*` / `color.sys.dark.*` token groups
- `--font-brand`, `--font-plain` — from `typography.ref.typeface.*`
- `--radius-*` — from `shape.corner.*`
- `--spacing-*` — from `spacing.*`

## Design Token Source

Token files in the parent directory (`color.tokens.json`, `typography.tokens.json`, etc.)
are in W3C DTCG format and can be imported into Figma via Tokens Studio.

## Figma Import

### Method 1: Tokens Studio (Recommended)
1. Install "Tokens Studio for Figma" plugin
2. Open plugin → Settings → Token Format → select "W3C DTCG"
3. Load `color.tokens.json`, `typography.tokens.json`, `shape.tokens.json`, `spacing.tokens.json`
4. Apply tokens to your Figma components

### Method 2: Styleframe Plugin
1. Install "Styleframe" Figma plugin
2. Drop `.tokens.json` files into the plugin
3. Click "Import" to create Figma variable collections
